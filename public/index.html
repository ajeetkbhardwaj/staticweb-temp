Verified Formalization Lean 4 · Mathlib
$$\forall f : \alpha \to \beta,\; \text{Injective}(f) \iff \forall x_1\, x_2,\; f(x_1) = f(x_2) \implies x_1 = x_2$$ 
theorem comp_injective {f : α → β} {g : β → γ}
    (hf : Injective f) (hg : Injective g) :
    Injective (g ∘ f) :=
  fun _ _ h => hf (hg h)
