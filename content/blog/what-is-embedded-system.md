An embedded system is a computer built to do one specific job — think traffic
lights, microcontrollers on a washing machine board, or an Arduino blinking an
LED. Unlike a PC, it runs firmware written in C/C++ directly on hardware.

In this course we cover the full journey: from number systems and assembly to
writing C drivers and booting your own board.
